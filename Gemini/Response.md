Welcome to Programming Fundamentals! Whether you joined us from an ICS background, Pre-Engineering, or an Associate Diploma in Electrical or Electronic Engineering, you are in the right place. ICS students bring a familiarity with syntax and basic logic, while Pre-Engineering and Diploma graduates bring robust analytical problem-solving and mathematical training. Programming is simply a tool to translate that logic into instructions a machine can execute.

To build a rock-solid foundation, here is a progressive curriculum of **60 coding problems**, spanning from basic arithmetic to 2D arrays and strings.

---

### Phase 1: Basic Input/Output & Arithmetic (Problems 1–8)

1. **Temperature Conversion:** Convert a temperature given in Celsius to Fahrenheit and vice versa.
2. **Rectangle Geometry:** Calculate the area and perimeter of a rectangle given its length and width.
3. **Variable Swap (With Temp):** Swap the values of two integer variables using a temporary variable.
4. **Variable Swap (Without Temp):** Swap two numbers using only arithmetic operations (`+` and `-`).
5. **Salary Breakdown:** Compute a worker's gross salary given their basic salary, house rent allowance (40% of basic), and dearness allowance (20% of basic).
6. **Cartesian Distance:** Calculate the Euclidean distance between two coordinate points `(x1, y1)` and `(x2, y2)`.
7. **Time Converter:** Convert a total given number of seconds into hours, minutes, and remaining seconds.
8. **Compound Interest:** Calculate the compound interest given principal amount, annual rate of interest, and time period in years.

---

### Phase 2: Conditional Statements (Problems 9–20)

9. **Even or Odd:** Determine whether a given integer is even or odd.
10. **Maximum of Three:** Find the largest of three given numbers using nested `if-else` statements.
11. **Leap Year Check:** Check whether a given year is a leap year (divisible by 4, but century years must be divisible by 400).
12. **Grading System:** Assign a letter grade (A, B, C, D, F) based on a student's percentage marks.
13. **Vowel or Consonant:** Check if an input character is a vowel or a consonant using `switch-case`.
14. **Basic Calculator:** Implement a simple calculator that performs addition, subtraction, multiplication, division, and modulo using `switch-case`.
15. **Valid Triangle (Angles):** Check if a triangle is valid given its three interior angles (sum must equal 180 degrees).
16. **Triangle Classification:** Classify a triangle as Equilateral, Isosceles, or Scalene based on its three side lengths.
17. **Electricity Bill Calculator:** Calculate utility bills with tiered rates (e.g., first 100 units at $1/unit, next 200 at $1.50/unit, etc.).
18. **Character Type Identifier:** Check if a character is an uppercase letter, lowercase letter, digit, or special symbol.
19. **Quadratic Roots:** Find the roots of a quadratic equation `ax^2 + bx + c = 0`, handling real, distinct, equal, and imaginary roots.
20. **Parking Fee Calculator:** Calculate parking charges based on vehicle type (car, bike, truck) and total hours parked.

---

### Phase 3: Loops & Iteration (Problems 21–35)

21. **Number Sequence & Sum:** Print all numbers from 1 to $N$ and calculate their cumulative sum using a `for` loop.
22. **Multiplication Table:** Print the multiplication table for any given integer up to 10.
23. **Factorial Calculator:** Compute the factorial of a positive integer using a `while` loop.
24. **Fibonacci Series:** Generate the Fibonacci sequence up to $N$ terms.
25. **Prime Number Checker:** Determine whether a given integer is a prime number.
26. **Digit Reversal:** Reverse the digits of a given integer (e.g., `1234` becomes `4321`).
27. **Palindrome Number:** Check if an integer reads the same forwards and backwards.
28. **Armstrong Number:** Check if a 3-digit number equals the sum of the cubes of its digits (e.g., `153`).
29. **GCD and LCM:** Find the Greatest Common Divisor and Least Common Multiple of two integers.
30. **Sum of Digits:** Calculate the sum of all individual digits in a given number.
31. **Right-Angled Triangle Pattern:** Print a right-angled star triangle of height $N$.
32. **Pyramid Pattern:** Print a centered star pyramid of height $N$.
33. **Guessing Game:** Implement a number-guessing loop where the program provides "Too high" or "Too low" hints until the user guesses correctly.
34. **Prime Range:** Print all prime numbers between two given bounds $A$ and $B$.
35. **Taylor Series Approximation:** Approximate the value of `sin(x)` or `cos(x)` using a Taylor series expansion up to $N$ terms.

---

### Phase 4: Functions & Modular Programming (Problems 36–45)

36. **Modular Prime Check:** Refactor problem #25 into a reusable boolean function `bool isPrime(int n)`.
37. **Permutations and Combinations:** Write functions to calculate factorial, `nPr`, and `nCr`.
38. **Power Function:** Implement a custom power function `power(base, exponent)` without using `<cmath>`.
39. **Recursive GCD:** Find the GCD of two numbers using a recursive function (Euclidean algorithm).
40. **Recursive Fibonacci:** Return the $N$-th term of the Fibonacci sequence using recursion.
41. **Pass-by-Reference Swap:** Write a void function that swaps two variables using reference parameters (`&`).
42. **Modular Menu Calculator:** Build a menu-driven program where each arithmetic operation is handled by a separate function.
43. **Modular Leap Year:** Write a boolean function `isLeapYear(int year)` and use it to count leap years in a century range.
44. **Base Converter:** Write functions to convert decimal numbers to binary and binary numbers to decimal.
45. **Overloaded Area Calculator:** Use function overloading to compute the area of a circle, rectangle, and triangle.

---

### Phase 5: 1D Arrays & Vectors (Problems 46–52)

46. **Min and Max in Array:** Find the maximum and minimum elements in an integer array of size $N$.
47. **Array Reversal:** Reverse the elements of an array in place.
48. **Linear Search:** Search for a target value in an unsorted array and return its index.
49. **Binary Search:** Implement binary search on a pre-sorted array.
50. **Element Frequency:** Count the occurrence frequency of each unique element in an array.
51. **Remove Duplicates:** Remove duplicate elements from a sorted array and return the new size.
52. **Merge Sorted Arrays:** Merge two sorted arrays of different sizes into a single sorted array.

---

### Phase 6: 2D Arrays & Matrices (Problems 53–56)

53. **Matrix Input and Display:** Read a 2D matrix of size $R \times C$ and compute the sum of all its elements.
54. **Diagonal Sum:** Calculate the sum of the main diagonal elements in a square matrix.
55. **Matrix Addition:** Add two matrices of identical dimensions.
56. **Matrix Multiplication:** Multiply two compatible matrices and store the result in a third matrix.

---

### Phase 7: Strings & Character Arrays (Problems 57–60)

57. **String Character Counter:** Count the number of vowels, consonants, digits, and whitespace characters in a sentence.
58. **String Palindrome:** Check if a given string is a palindrome, ignoring spaces and capitalization.
59. **Character Frequency Table:** Count and display the frequency of every alphabet letter in a string.
60. **Title Case Formatter:** Capitalize the first letter of every word in an input sentence.
