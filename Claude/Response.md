# 60 Problems for Teaching Programming Fundamentals

These problems are language-agnostic (they work in C, C++, Python, or Java) and are ordered so each section builds on the previous one. Several use engineering contexts (circuits, signals, units) and everyday contexts (money, time, marks), so students from ICS, pre-engineering, and diploma backgrounds all find something familiar.

## A. Input, Output, and Arithmetic
1. Print your name, program, and city in a formatted block.
2. Read two numbers and print their sum, difference, product, quotient, and remainder.
3. Convert temperature between Celsius and Fahrenheit.
4. Compute the area and perimeter of a rectangle and the area and circumference of a circle.
5. Given voltage and resistance, compute current (Ohm's law) and power.
6. Swap two variables, first using a temporary variable, then without one.

## B. Conditionals
7. Check whether a number is positive, negative, or zero.
8. Check whether a number is even or odd.
9. Find the largest of three numbers.
10. Check whether a year is a leap year.
11. Convert percentage marks to a grade (A, B, C, D, F).
12. Build a simple calculator using `switch`/`match` (+, −, ×, ÷, with divide-by-zero handling).
13. Given three side lengths, decide if they form a triangle and classify it (equilateral, isosceles, scalene).
14. Compute an electricity bill using slab-based tariffs.

## C. Loops
15. Print numbers from 1 to N.
16. Print the multiplication table of any number.
17. Compute the sum of the first N natural numbers.
18. Compute the factorial of N.
19. Count the digits in an integer.
20. Reverse an integer and check whether it is a palindrome.
21. Compute the sum of the digits of a number.
22. Print the first N Fibonacci numbers.
23. Check whether a number is prime, then print all primes up to N.
24. Compute the GCD and LCM of two numbers (Euclid's algorithm).

## D. Nested Loops and Patterns
25. Print a right-angled triangle of stars.
26. Print a pyramid of stars.
27. Print a number triangle (Pascal's triangle).
28. Print all Armstrong numbers between 1 and 1000.

## E. Functions
29. Write functions for `max`, `min`, and `abs` of numbers.
30. Write `isPrime(n)` and use it to list twin primes.
31. Write a function to convert between decimal and binary.
32. Write a function `power(base, exp)` without using the built-in operator.
33. Write functions to compute simple and compound interest.
34. Demonstrate pass-by-value vs pass-by-reference with a swap function.

## F. Arrays / Lists
35. Read N numbers and print them in reverse order.
36. Find the sum, average, maximum, and minimum of an array.
37. Search for an element (linear search), then binary search on sorted data.
38. Count even and odd elements.
39. Remove duplicates from an array.
40. Sort an array using bubble sort.
41. Rotate an array left or right by K positions.
42. Merge two sorted arrays into one sorted array.

## G. Strings
43. Count vowels, consonants, digits, and spaces in a string.
44. Reverse a string and check whether it is a palindrome.
45. Convert a string to uppercase/lowercase without library functions.
46. Count the words in a sentence.
47. Check whether two strings are anagrams.
48. Implement a Caesar cipher (encrypt and decrypt).

## H. Two-Dimensional Arrays
49. Read and print a matrix, then compute its transpose.
50. Add and multiply two matrices.
51. Compute row sums and column sums, and the sum of both diagonals.
52. Check whether a matrix is symmetric.

## I. Recursion
53. Compute the factorial and Fibonacci recursively, then compare with the iterative versions.
54. Compute the sum of digits recursively.
55. Solve the Tower of Hanoi.
56. Implement recursive binary search.

## J. Structures, Files, and Mini-Projects
57. Define a `Student` structure/class (name, roll number, marks), then store and display N students.
58. Read marks from a text file and write a result report (average, highest, lowest) to another file.
59. Build a menu-driven bank account simulator (deposit, withdraw, balance check).
60. Build a number-guessing game with attempt counting and hints.

## Teaching Notes

- **Pacing:** Sections A–D suit weeks 1–5. Functions and arrays follow in weeks 6–9. Strings, matrices, recursion, and files suit the remaining weeks.
- **Mixed backgrounds:** ICS students may breeze through sections A–C, while diploma students may need extra time with abstract logic. Pair students across backgrounds, and give the engineering-flavored problems (5, 14, 31, 48) as bridges.
- **Variations:** Ask for each problem to be solved twice, as a first version and as a version with input validation. This builds the habit of thinking about edge cases early.
- **Assessment:** Problems 57–60 work well as small graded mini-projects that combine several earlier concepts.
