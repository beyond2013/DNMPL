Automata Lab

Describe a language, get its minimal DFA and a regular expression, then test your own attempts against it.

Supported phrases
  • Counts: even / odd number of a’s, number of a’s divisible by 3, number of a’s mod 3 = 1, exactly / at least / at most 2 b’s
  • Patterns: starts with ab, ends with ba, contains aa, any string, empty string
  • Combine: X followed by Y (or then), X and Y, X or Y, not X. Precedence: or, then and, then followed by. No parentheses.
  • In a followed by chain, a count such as “even number of a’s” describes a block made only of a’s. On its own it counts a’s anywhere in the string.
  • Symbols are single characters, and case is ignored.
